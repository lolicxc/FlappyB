Swimmy is a fun, casual game inspired by Flappy Bird, set in an underwater world.
Players control a fish swimming through obstacles, collecting bubbles, and trying to achieve the highest score possible.
The game features colorful gameplay, a collage-style underwater background, and a simple one-button control.

##Features

-Single-player mode

-Colorful underwater graphics

-Collage-style art inspired by marine life

-Easy and addictive gameplay

-Works on Windows (EXE included)
